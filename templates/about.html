🔍 Project Overview

This is a small-scale web search engine capable of crawling, indexing, and ranking web pages based on TF-IDF scores.

🛠 Tech Stack
  • Crawler: Python (Requests + BeautifulSoup)
  • Indexing: Inverted Index with TF-IDF
  • Backend: Flask Web Framework
  • Frontend: Bootstrap 5
